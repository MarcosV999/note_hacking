### 1. Desarrollo y Documentación de un "Home Lab" (Active Directory)

En el entorno corporativo, el Pentesting se trata mayoritariamente de atacar entornos de Windows y Active Directory (AD).

- **El Proyecto:** Crea un laboratorio con una máquina Windows Server (Domain Controller) y un par de clientes (Windows 10/11) vulnerables usando VirtualBox o VMware.
    
- **Qué evidencia:** Demuestra que entiendes la **administración de redes**, protocolos como Kerberos, y configuraciones de seguridad (GPOs).
    
- **Entregable:** Un post en tu blog explicando cómo configuraste el laboratorio y una guía de "Hardening" (cómo asegurarías tú ese entorno después de romperlo).

### 2. Escribir tus propios "Write-ups" Profesionales

No hagas el típico write-up de "puse este comando y salió la flag". Haz un reporte que un CEO pueda leer.

- **El Proyecto:** Elige máquinas de dificultad media/alta en **Hack The Box** o **TryHackMe**.
    
- **Qué evidencia:** Demuestra **capacidad de reporte**. En el pentesting real, el producto final no es el hack, es el informe.
    
- **Entregable:** Un PDF o post en tu blog dividido en:
    
    - _Executive Summary:_ Resumen para gente no técnica.
        
    - _Technical Details:_ Explicación del exploit.
        
    - _Remediation:_ Pasos exactos para que el desarrollador arregle el fallo.

### 3. Automatización con Bash y Python (Herramientas Propias)

Un pentester eficiente no solo usa herramientas de otros, sino que crea las suyas para ahorrar tiempo.

- **El Proyecto:** Crea un script en Bash o Python que automatice una fase del pentesting. Por ejemplo, un "Recon Tool" que use `nmap`, `gobuster` y `subfinder` y guarde los resultados en carpetas organizadas.
    
- **Qué evidencia:** Demuestra tus conocimientos de **scripts y automatización** (los "nuts and bolts" del día a día).
    
- **Entregable:** Un repositorio en GitHub con código limpio, bien comentado en inglés y un buen archivo `README.md`.

### 4. Análisis de Vulnerabilidades Web (Bug Bounty Lite)

- **El Proyecto:** Elige una aplicación web de código abierto o una plataforma de práctica (como OWASP Juice Shop) y realiza una auditoría completa enfocada en el **OWASP Top 10**.
    
- **Qué evidencia:** Demuestra que entiendes vulnerabilidades críticas como SQLi, XSS o IDORs.
    
- **Entregable:** Una tabla comparativa de las vulnerabilidades encontradas, su impacto (CVSS Score) y cómo mitigarlas.
